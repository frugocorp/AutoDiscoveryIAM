# CreateUser Command

Este directorio contiene la implementación vertical slice del comando CreateUser para el feature Users, siguiendo exactamente la estructura y convenciones del feature Posts.

Incluye:
- Command, Handler, Validator, Repository
- DTOs de request/response
- Endpoint
- Documentación y ejemplos

Todos los archivos deben basarse en su símil de Posts/CreatePost y adaptarse al dominio User.
